# 卷积码 S3 实验项目记录

## 1. 项目目标

本项目面向 **300 bit 高速电文**，研究卷积码在不同码率、不同判决方式、不同电文组织方式和不同滑窗译码参数下的性能。

主要回答以下问题：

1. 码率 \(1/2、2/3、3/4\) 对 BER、FER 和有效吞吐有什么影响；
2. 硬判决与浮点软判决的性能差距有多大；
3. 整块编码与 \(50\times6、100\times3、150\times2\) 时隙组织的可靠性和时延有什么区别；
4. 回溯深度 \(D\)、窗口长度 \(W\)、滑动步长 \(S\) 如何影响可靠性、时延、存储和计算量；
5. Q3～Q8 量化软判决相对 Float 的性能损失是多少；
6. 最终应如何选择可靠性、吞吐、时延、存储和平衡方案。

## 2. 公共链路和参数

### 2.1 卷积码参数

| 参数 | 设置 |
|---|---|
| 信息长度 | 300 bit |
| 约束长度 | \(K=7\) |
| 生成多项式 | \(171/133\)，八进制 |
| 母码率 | \(1/2\) |
| 打孔码率 | \(2/3、3/4\) |
| 调制 | BPSK |
| 映射 | \(0\rightarrow +1,\ 1\rightarrow -1\) |
| 信道 | 符号级离散 BPSK-AWGN |
| 判决方式 | Hard、Float Soft、Q3～Q8 |
| 主要译码器 | 完整块、有限回溯、真滑窗 Viterbi |

码率统一定义为：

$$
R=\frac{\text{原始输入长度}}{\text{实际发送编码长度}}
$$

BPSK符号信噪比为：

$$
\gamma_s=10^{\frac{E_s/N_0\text{(dB)}}{10}}
$$

噪声方差为：

$$
\sigma^2=\frac{1}{2\gamma_s}
$$

软判决输入可表示为：

$$
LLR=\frac{2y}{\sigma^2}
$$

有效吞吐定义为：

$$
G_{\mathrm{eff}}=R(1-FER)
$$

### 2.2 正式仿真规模

| 参数 | 设置 |
|---|---|
| \(E_s/N_0\)范围 | \(-5\sim10\) dB |
| SNR间隔 | 0.5 dB |
| 每条曲线点数 | 31 |
| 最低帧数 | 1000 |
| 目标误帧数 | 200 |
| 最大帧数 | 50000 |

停止规则：

$$
N_{\mathrm{frames}}\ge1000
\quad\text{且}\quad
N_{\mathrm{FE}}\ge200
$$

满足以上条件时允许提前停止；否则运行至50000帧。

BER和FER分别为：

$$
BER=\frac{N_{\mathrm{bit,error}}}
{300N_{\mathrm{frames}}}
$$

$$
FER=\frac{N_{\mathrm{frame,error}}}
{N_{\mathrm{frames}}}
$$

## 3. Stage09：完整块 AWGN 基准

### 3.1 实验目的

建立三种码率下完整块 Viterbi 的正式 BER、FER 基准，并比较硬判决与浮点软判决。

### 3.2 实验方法

300 bit 电文完成卷积编码、打孔、BPSK和AWGN传输后，一次性接收完整码流，再执行完整块 Viterbi 译码。

实验组合：

| 码率 | 判决 |
|---|---|
| R12 | Hard、Float Soft |
| R23 | Hard、Float Soft |
| R34 | Hard、Float Soft |

### 3.3 优化内容

- 统一使用 \(E_s/N_0\)；
- 每帧独立生成噪声；
- 增加两层SNR网格；
- 增加BER、FER置信区间；
- 零错误点在CSV中保留为0，在对数图中省略，不再伪造水平error floor。

### 3.4 主要结果

- 同一判决方式下，可靠性排序为：

$$
R12>R23>R34
$$

- 同一码率下，Float Soft明显优于Hard；
- 软判决达到相同FER时所需SNR更低；
- R34吞吐上限最高，但可靠性最弱。

## 4. Stage10：有限回溯深度实验

### 4.1 实验目的

研究有限回溯深度 (D) 对可靠性、存储、决策时延和计算量的影响，并寻找完整块译码的低存储替代方案。

### 4.2 实验参数

| 参数    | 设置                 |
| ----- | ------------------ |
| 码率    | R12、R23、R34        |
| FER层级 | 约0.3、0.1、0.03      |
| 回溯深度  | 35、49、70、84、98、112 |
| 参考方案  | 完整块回溯 (D=306)      |
| 判决    | Float Soft         |

### 4.3 实验方法

在每个码率的三个代表FER工作点上，对不同回溯深度进行有限回溯译码，并与完整块结果比较。

相对FER增幅为：

$$
\Delta FER_{\mathrm{rel}}
=========================

\frac{FER_D-FER_{\mathrm{block}}}
{FER_{\mathrm{block}}}
$$

### 4.4 优化内容

* 增加R34；
* 每个码率增加三个FER层级；
* 增加D70、D84、D98、D112重点比较；
* 增加总译码器内存、ACS次数、回溯操作数和时延；
* 修复原空白“内存—可靠性”图；
* 最终图包含三码率共18个有效点。

### 4.5 主要结果

* D35、D49虽然存储较低，但FER损失明显；
* D70后可靠性快速接近完整块；
* D84仍存在部分场景超过5%的FER增幅；
* D98、D112基本接近完整块；
* 统一有限回溯推荐为D112。

| 回溯深度 | 可靠性    | 内存 | 建议       |
| ---- | ------ | -- | -------- |
| D35  | 较差     | 最低 | 不推荐      |
| D49  | 偏低     | 较低 | 不推荐      |
| D70  | 明显改善   | 中等 | 可作低时延候选  |
| D84  | 接近完整块  | 中等 | 部分场景仍有损失 |
| D98  | 很接近完整块 | 较高 | 平衡候选     |
| D112 | 最稳定    | 较高 | 统一推荐     |

## 5. Stage11：软判决量化实验

### 5.1 实验目的

研究软信息量化位宽对FER、SNR损失、存储、时延和饱和比例的影响，寻找接近Float性能的低位宽方案。

### 5.2 实验参数

| 参数    | 设置                      |
| ----- | ----------------------- |
| 码率    | R12、R23、R34             |
| 量化模式  | Q3、Q4、Q5、Q6、Q7、Q8、Float |
| SNR范围 | (-5\sim10) dB           |
| 目标比较点 | (FER=0.1)               |
| 译码    | 完整块软判决Viterbi           |

量化损失定义为：

$$
\Delta SNR_Q
=

SNR_Q(FER=0.1)-SNR_{\mathrm{Float}}(FER=0.1)
$$

### 5.3 优化内容

* 补齐Q5、Q7、Q8；
* 增加R34；
* 补齐完整SNR曲线；
* 将Float作为独立分类，不再错误画在横轴64位置；
* 增加FER=0.1处的SNR损失图；
* 饱和统计改为比例，不再只画绝对次数；
* 减少图例过载。

### 5.4 主要结果

| 量化方式 | 相对Float性能 | 结论     |
| ---- | --------- | ------ |
| Q3   | 损失最大      | 不推荐    |
| Q4   | 明显改善      | 极限内存方案 |
| Q5   | 接近Float   | 可用     |
| Q6   | 很接近Float  | 良好折中   |
| Q7   | 几乎等同Float | 推荐     |
| Q8   | 最接近Float  | 性能优先推荐 |

典型结果：

* Q8最坏SNR损失约0.008 dB；
* Q7约0.011 dB；
* Q5约0.057 dB；
* 最终性能和平衡推荐Q8，内存优先推荐Q4。

## 6. Stage13：真滑窗Viterbi参数实验

### 6.1 实验目的

验证真滑窗Viterbi实现，并通过控制变量研究窗口长度 (W)、滑动步长 (S) 和回溯深度 (D) 对FER、时延、存储和计算量的影响。

### 6.2 真滑窗定义

译码器只保存有限的 (W\times64) survivor缓存，不保存完整帧历史。

参数含义：

* (W)：窗口长度；
* (S)：每次窗口推进和输出的步长；
* (D)：做可靠判决所需的回溯深度。

必须满足：

$$
D\le W
$$

并保证输出不丢失、不重复：

$$
N_{\mathrm{lost}}=0
$$

$$
N_{\mathrm{duplicate}}=0
$$

### 6.3 正式控制变量配置

#### W实验

固定：

$$
S=16,\quad D=70
$$

改变：

$$
W\in{96,128,160,192}
$$

#### S实验

固定：

$$
W=160,\quad D=70
$$

改变：

$$
S\in{8,16,25,50}
$$

#### D实验

固定：

$$
W=160,\quad S=16
$$

改变：

$$
D\in{35,49,70,84,98,112}
$$

每组均覆盖R12、R23、R34和完整31点SNR网格。

### 6.4 仿真规模

| 实验        |         点数 |
| --------- | ---------: |
| CONTROL_W |        372 |
| CONTROL_S |        372 |
| CONTROL_D |        558 |
| 合计        |       1302 |
| 总帧数       | 36,789,382 |

### 6.5 优化内容

* 将原“完整历史+窗口回溯”改为真正有限缓存；
* 使用 (W\times64) survivor环形缓存；
* W、S、D真实参与窗口推进和输出；
* 最终flush不依赖完整306时刻历史；
* 增加无噪声测试；
* 增加丢失bit、重复bit和输出长度Gate；
* 按W、S、D分别进行单变量大规模实验。

### 6.6 主要结果

* W增大主要提高缓存占用和可用历史范围；
* S主要影响输出频率、P95时延和窗口触发次数；
* D主要影响可靠性、回溯计算和内存；
* D过小会造成明显FER损失；
* D达到70～112后性能逐渐接近完整块；
* 当前D参数总结图若跨完整SNR取中位数会掩盖差异，应优先参考Stage10在FER=0.1处的结果。

原balanced候选：

| 码率  |   W |  S |   D |
| --- | --: | -: | --: |
| R12 | 128 | 25 |  70 |
| R23 | 128 | 25 |  98 |
| R34 | 160 | 25 | 126 |

说明：D126未纳入本轮完整控制变量重跑，因此正式控制变量结论只覆盖D35～D112。

## 7. Stage14：整块与时隙组织对比

### 7.1 实验目的

研究300 bit电文采用整块组织和不同时隙组织时，对BER、FER、有效吞吐、首次输出、平均/P95决策时延、缓存和计算量的影响。

### 7.2 组织方式

| 组织编号 | 方式           | 译码         |
| ---- | ------------ | ---------- |
| A    | Block300     | 完整块Viterbi |
| B    | (50\times6)  | 真滑窗Viterbi |
| C    | (100\times3) | 真滑窗Viterbi |
| D    | (150\times2) | 真滑窗Viterbi |

时隙连续编码要求：

* 编码器状态跨slot连续；
* 打孔相位跨slot连续；
* 中间slot不清零；
* 中间slot不加尾；
* slot到达后更新接收缓存并触发滑窗；
* 最后一个slot后统一终止。

### 7.3 实验规模

| 项目         |   数量 |
| ---------- | ---: |
| Hard       | 372行 |
| Float Soft | 372行 |
| 总计         | 744行 |
| 码率         |   3种 |
| 组织方式       |   4种 |
| 每个组合SNR点   |   31 |

### 7.4 优化内容

* 修复原先“完整码流拼接后一次性译码”的问题；
* 实现slot真实到达驱动译码；
* 补齐Hard正式实验；
* 保留Soft正式结果；
* 将四种组织全部纳入Stage15；
* 增加首次输出、平均/P95、缓存、ACS和回溯操作数；
* 删除高SNR虚假error floor；
* 重构图例和子图布局。

### 7.5 主要结果

1. 同一码率和判决方式下，四种组织的BER、FER几乎完全重合；
2. 原因是四种组织最终传输的编码符号序列相同，slot划分主要改变到达和调度时间；
3. Soft明显优于Hard；
4. 时隙组织的主要优势是提前输出，而不是提高最终FER；
5. (50\times6)通常具有较低平均和P95决策时延；
6. 首次输出时延不是随slot长度简单单调变化，而与W、S、D及窗口触发门限共同有关。

## 8. Stage15：最终集成

### 8.1 实验目的

统一集成Stage09、10、11、13、14的正式结果，输出最终BER、FER、有效吞吐、量化损失、回溯权衡、滑窗时延和方案推荐。

### 8.2 最终矩阵

```text
stage15_final_scheme_matrix.csv
```

共3447行，包含：

* Stage09完整块Hard/Float；
* Stage10有限回溯；
* Stage11 Q4/Q6/Q8/Float；
* Stage13滑窗候选和W/S/D正式数据；
* Stage14 Hard/Soft四种组织。

### 8.3 公平比较方法

#### 固定SNR比较

统一在：

$$
E_s/N_0=2\ \mathrm{dB}
$$

比较：

* BER；
* FER；
* 有效吞吐；
* CPU时间；
* 内存。

#### 固定FER比较

统一在：

$$
FER=0.1
$$

通过相邻真实点进行对数域插值：

$$
SNR_{0.1}
=========

SNR_1+
\frac{\ln(0.1)-\ln(FER_1)}
{\ln(FER_2)-\ln(FER_1)}
(SNR_2-SNR_1)
$$

### 8.4 最终推荐

| 推荐类型  | 最终方案                | 比较条件      |
| ----- | ------------------- | --------- |
| 可靠性优先 | R12完整块Float         | 固定2 dB    |
| 吞吐优先  | R34 balanced滑窗      | 固定2 dB    |
| 时延优先  | R23 latency-first滑窗 | (FER=0.1) |
| 内存优先  | R12 latency-first滑窗 | (FER=0.1) |
| 平衡方案  | R12 latency-first滑窗 | (FER=0.1) |

注意：

* “FER=0”仅表示有限仿真帧内未观察到误帧，不代表真实FER绝对为0；
* 五类推荐使用了不同比较基础，不能直接理解为同一排行榜；
* R12可靠性高但吞吐上限低，平衡方案仍需根据实际业务需求选择。
