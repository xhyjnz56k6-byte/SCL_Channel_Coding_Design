```text
帧池 payload
  ↓
BCH case 选择、编码、译码适配
  ↓
BPSK / 高斯噪声 / AWGN（S1、S2 共用）
  ↓
S1：硬判决 → BCH 译码 → 指标

  ↓
summary.csv / complexity_summary.csv / 图表数据
```

## 你可以这样理解两者的边界

- S1：在 AWGN 下比较“哪一种 BCH 码长与组织方式更适合 200/300 bit 低速电文”。
- S2：固定或选取 S1 的 BCH 候选后，比较它在 AWGN、多径、频偏、遮挡、突发错误等信道下是否仍可靠，并单独测量交织对突发错误的影响。

S1、S2 共用的 BCH 算法主体没有重复实现。S2 的新增部分，主要是“信道模型、接收机处理、交织器以及正式实验 runner”。
