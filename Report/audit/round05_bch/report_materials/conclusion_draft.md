# 第4章结论草案

1. 分组方案结构简单、使用固定 BCH(15,11,1) 单错查表，但整帧纠错能力受各 15 bit 子块边界约束；整块方案以更大的 BM+Chien 工作量换取跨整帧的 t=6、t=10 或 t=14 纠错能力。
2. 200 bit 正式方案应比较 S200 与 B200；300 bit 应以 B300-390 为主基线，并把 B300-426 作为增加 36 个发送比特、降低实际码率以增强纠错能力的候选，不应把二者写成同一方案。
3. S1 AWGN 五方案数据的计数、BER/FER、成功状态和码率一致；正式曲线应使用按实际码率转换的 Es/N0 横轴。
4. B300-426 在 W8 目标 FER 可插值范围内相对 B300-390 有小幅性能优势，但代价是更长码字与更大的译码工作量。具体 dB 数值只在两条曲线均跨越目标 FER 时引用。
5. 固定多径实验采用单位能量三抽头信道和已知信道线性 MMSE；结论只适用于该固定 tap/delay 与理想信道知识条件。
6. Stage10 的 30°场景是从0°线性累积到帧末30°的相位漂移，无补偿且取实部硬判决；不能写成固定30°初相位或真实多普勒信道。
7. 遮挡实验是调制符号域连续置零且遮挡期间仍有 AWGN，不等同于接收端已知位置的软擦除。
8. 突发实验是在 AWGN 硬判决后施加连续 bit 翻转；交织结论仅适用于冻结的突发长度、深度和停止规则，不外推为全部信道的通用最优方案。
9. 译码时延是当前 Windows/MinGW Release 软件测量，不代表 FPGA、ASIC 或实时硬件时延。
