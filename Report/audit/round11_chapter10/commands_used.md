## Evidence and structure

```powershell
Select-String -Path Report/sections/*.tex -Pattern '\\label\{|\\caption\{'
Select-String -Path Report/sections/*.aux -Pattern '\\newlabel'
```

## Build

```powershell
xelatex -jobname=round11_main -no-pdf -interaction=nonstopmode -halt-on-error main.tex
xdvipdfmx -q -E -o main.pdf round11_main.xdv
```

XeLaTeX was run repeatedly until references and outlines stabilized. A dedicated job name was used because the existing `main.log` generated by the local `latexmk` path contained invalid leading bytes.

## Scope and hash audit

```powershell
git diff --name-only HEAD -- 'Report/sections/0[1-9]_*.tex'
git diff --name-only HEAD -- 'Task/**/*.csv'
Get-FileHash -Algorithm SHA256 <each tracked Task CSV>
```

The sorted `path<TAB>sha256` rows for 17591 tracked Task CSV files were hashed again, producing aggregate SHA-256 `b87ffa0c33a13aaae5cfc845fb8fbc6a5faeb039e5ced607137a89a9057cece8`.
