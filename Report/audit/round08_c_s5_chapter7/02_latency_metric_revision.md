# 时延统计口径修订

## 数据源

`Task/Comparison/S5/results/stage11/s5_latency_comparison.csv`。

## 表7.6修订

表7.6主表保留卷积码和LDPC的平均译码时间、平均P95译码时间，并新增两方案的 `maxDecodeTimeUs`，正式名称为“最大观测译码时间”。该指标是有限样本中的最大观测值，不称为严格最坏情况时延。

为避免主表过宽，平均接收算法时间以同一编号的续表给出。接收算法时间定义为信道处理时间加译码时间。

## 跨信噪比汇总

平均译码时间和P95译码时间先在每个正式 `E_s/N_0` 工作点内统计，再对31个工作点等权取算术平均；它们不是将不同工作点的所有帧直接池化后的全局统计量。

## 迭代统计

表7.7中的平均迭代、P95迭代和达到32次上限的帧比例采用同一两级口径：逐信噪比点统计，再对31个工作点等权取算术平均。迭代统计覆盖所有LDPC帧，不只覆盖成功译码帧。
