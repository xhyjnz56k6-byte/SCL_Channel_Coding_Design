# 表格与图题字号审计

第7章在局部作用域中使用：

```tex
\captionsetup{font=small,labelfont=normalfont,skip=0.6em}
```

因此图题和表题均比 `ctexrep` 的普通正文小一级，子图(a)/(b)标签保持 `\small`，表注可使用 `\footnotesize`。该设置不改变第4～6章及其他章节的caption样式。

表7.1、7.2、7.4、7.5、7.6、7.7、7.8均逐页检查：无横向溢出，数值列与N/A可辨认。表7.6因增加最大观测译码时间而拆为同编号续表，避免缩放到不可读字号；表7.7仍为LDPC迭代表，表7.8仍为六信道综合推荐表。
