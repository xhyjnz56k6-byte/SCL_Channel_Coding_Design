# Stage11 软信息量化报告

Q4 在四个场景合计 800 帧的 clipping prescan 中，`clipMax={2,3,4,6}` 对 float 的 mismatch frames 分别为 51、78、106、197，因此全局选择 clipMax=2；该范围用于全部 SNR 和全部正式位宽。

正式 4000 帧结果中，Q3/Q4 的最坏 BER/FER 增幅分别为约 185.29%/193.75% 和 28.00%/28.41%，均不满足门限。Q6 的最坏 BER 增幅为 9.804%，最坏 FER 增幅为 6.780%，整数 overflow=0、路径度量 saturation=0，满足每点不超过 10% 的门限，推荐 `SOFT_Q6`。

四场景平均译码时延约为 float 280.24 us、Q3 274.71 us、Q4 262.91 us、Q6 253.53 us。输入存储以 R12 单帧为例由 float 的 4896 bytes 降为 Q6 的 459 bytes。软件结果表明 Q6 在当前实现中兼顾性能和输入带宽，但结论仅适用于当前量化合同与代表点。
