# α 曲线重选报告

Gate：PASS。

主证据是每个实际码长独立的 FER、平均译码时延和复杂度曲线，所有图均包含 BP、α=0.60 至 1.00 的九个候选，未插值、未平滑。复杂度定义为平均 edge-message updates/frame。N480/N560 的 MS 虽有最低样本 FER 和最小时延，但专项审计证明其时延优势与错误合法码字快速早停强相关，可靠性 Gate 不通过。α=0.90 相比 α=0.95 的 FER 差异小且 wrong-valid 风险更低，故 N480/N560 冻结 0.90；N640 的 waterfall FER 在 α=0.80 附近最优且稳定，冻结 0.80。旧 N480/N560 α=1.00 结论被推翻。
