# stage08_multipath_formal 正式结论

## 解释边界

8 个 Case 使用同一固定多径、归一化、完整线性卷积和 MMSE，但使用各自在
formal 前冻结的 Eb/N0 网格。因此“自身最高冻结工作点”的 BER/FER 可用于说明
该方案在本次实验覆盖内达到的可靠性，不等同于在完全相同 Eb/N0 或 SNR 点上的
严格横向优势。没有插值、拟合或动态补点，不存在单一脱离工作点的绝对最优方案。

## 200 bit

- 自身最高冻结工作点可靠性：`K200_S15`，在 Eb/N0=16 dB、
  SNR=17.472 dB 时 BER=`6.7e-6`、FER=`0.0006`（30/50000 帧）。
- 最高码率：`K200_M255K207`，encodedLength=248，
  actualRate=`0.8064516`；其最高工作点 FER=`0.00192`。
- 最低平均 BCH 译码时延：`K200_S15`，约 `11.52 μs`。
- 最低平均 MMSE 时延：`K200_M255K207`，约 `5.50 μs`；各方案 MMSE
  时延主要随 encodedLength 变化。
- 误纠统计必须结合工作点解释；所有原始 miscorrection 整数均保留在 results。
- 可靠性优先：`K200_S15`（限本次冻结高端工作点结论）。
- 码率优先：`K200_M255K207`。
- 低译码时延优先：`K200_S15`。
- 综合折中：`K200_M255K207`，因为它在 248 bit 最短发送长度下提供最高码率、
  最低 MMSE 时延，并在自身高端工作点保持低 FER；若可靠性优先于频谱效率，
  选择 `K200_S15`。

## 300 bit

- 自身最高冻结工作点最低 BER：`K300_S15`，在 Eb/N0=16 dB 时
  BER=`7.533e-6`；最低 FER：`K300_M511K421`，在 Eb/N0=10 dB、
  SNR=11.871 dB 时 BER=`9.933e-6`、FER=`0.00032`（16/50000 帧）。
- 最高码率：`K300_M511K421`，encodedLength=390，
  actualRate=`0.7692308`。
- 最低平均 BCH 译码时延：`K300_S15`，约 `17.05 μs`。
- 最低平均 MMSE 时延：`K300_M255K207`，约 `9.00 μs`；其双块 BCH
  译码时延约 `34.64 μs`。
- 可靠性优先：`K300_M511K421`（限本次冻结高端工作点结论）。
- 码率优先：`K300_M511K421`。
- 低译码时延优先：`K300_S15`。
- 综合折中：`K300_M511K421`，其 390 bit 发送长度、最高码率和自身高端工作点
  的最低 BER/FER 同时占优；若软件译码时延是首要约束，则选择 `K300_S15`。

## 实现复杂度

S15 方案由多个短 BCH(15,11) 分块与查表译码组成，单块简单但块数多；
255 双块方案需要两次母码译码；421/385 整块方案只组一个块，但有限域母码更大，
其中 385/t=14 的平均译码时延最高。MMSE 实现对所有 Case 相同，矩阵维度由实际
encodedLength 决定。
