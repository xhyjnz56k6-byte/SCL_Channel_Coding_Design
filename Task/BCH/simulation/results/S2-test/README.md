# BCH S2-test local results

This directory is a local archive and is not intended to be added to Git.

- `batch1/`: fixed multipath/MMSE S2 batch;
- `batch2_original/`: original S2 batch-2 results;
- `batch2_corrected/`: corrected S2 batch-2 results;
- `burst_redesign/`: burst redesign and published review results.

The migration audit in
`Task/BCH/simulation/stages/S2-test/results_migration_audit.csv` records
pre/post file counts, byte totals, and key SHA-256 checks.
