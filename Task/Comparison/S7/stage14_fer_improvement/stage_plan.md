# Stage14 计划

目标：按码型分别计算 FER 绝对改善、相对降低、改善倍数、目标 FER Es/N0 增益、位置敏感性、突发容限和推荐排名。

非目标：不混排 BCH/CC/LDPC，不对不可插值点制造数值，不把不同跨度 CC 解释为纯方法差异。

排名权重公开冻结为：平均 Formal FER 40%、高工作点最坏起点 FER 30%、bufferBits 15%、解交织 CPU 15%。
