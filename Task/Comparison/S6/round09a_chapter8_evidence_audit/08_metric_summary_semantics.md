# S6_METRIC_SUMMARY_SEMANTICS

`S6_metric_summary.csv` is generated by `stage08_s6_final_report/finalize_s6.py`.

Rows: BCH 2 schemes, CC 8 schemes, LDPC 2 schemes; every row covers 31 Es/N0 points.

`totalFrames`, `totalBitErrors`, and `totalFrameErrors` are pooled sums across all selected SNR points. `weightedAvgDecodeTimeUs` is frame-weighted: sum(point avg decode time * point frames) / sum(point frames). It is frame pooling, not equal-weight SNR-point averaging.

`maxObservedDecodeTimeUs` is max over source point maxima. `decoderMemoryBytes` is max/fixed modeled memory. `zeroBerPoints` and `zeroFerPoints` count SNR points with raw zero values.

The file has no P95/P99 columns. For P95/P99 tables, use formal source CSVs or figure data directly.
